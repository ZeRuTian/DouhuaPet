# 豆花 macOS 桌面宠物 PRD

版本：0.5.1（防抖真实视频 + 3D 骨骼运行合同）

日期：2026-07-13

## 1. 产品定义

豆花是一款仅供主人本机使用、原生、轻量、离线的 macOS 桌面宠物。最高优先级是“画面中的猫持续像真实豆花在活动”，不再以动作数量或状态机完整度为优先目标。

## 2. 0.5 核心决策

- 主渲染器：透明 HEVC 连续视频，不是 PNG 精灵序列。
- 视觉来源：同一段真实豆花镜头，保留真实毛纹、骨架、曝光和惯性的时间连续性。
- 制作方式：macOS Vision 逐帧前景分割，整个镜头共用固定裁切和尺度；分割后再对固定参考纹理做平移配准，抵消手持相机位移。
- 播放方式：`AVQueuePlayer + AVPlayerLooper + SKVideoNode`，30fps 硬件解码。
- 当前动作：连续休息、呼吸、眼神变化、转头、耳朵和尾巴微动。
- 当前不做主动横向巡逻：现有素材没有合格连续步态，静态姿势滑行不符合真实猫运动。
- 旧 v2/v3/v4 逐帧动画退出运行包，仅作为制作历史归档。

## 3. 运行范围

### 3.1 连续活体画面

- 主片段为 480×440、30fps、10.13 秒的 HEVC-with-alpha 视频，共 304 个连续时间样本。
- 不含音频、原始背景或人物；只保留豆花前景。
- 循环落点在后半段搜索与起点姿态最接近的帧，落点前后无黑帧、白闪和尺寸重置。
- 暂停、隐藏、拖动和系统休眠会暂停播放器；恢复时从当前时间继续。
- 不对整只猫做缩放呼吸、网格拉伸、双图溶解或帧间光流伪造。

### 3.2 窗口与日常控制

- 透明、无边框、非激活浮窗，不抢当前应用键盘焦点。
- 默认置顶、加入所有 Spaces，并作为全屏辅助窗口显示。
- 命中遮罩用于区分豆花与透明区；透明区穿透鼠标事件。
- 鼠标移动超过 4 pt 后才激活拖动，拖动中暂停视频，释放后继续并夹回有效屏幕。
- 菜单栏和右键菜单提供召回、暂停/继续、显示/隐藏、体型、重置和退出。
- UserDefaults 保存体型、显隐、暂停、屏幕和归一化位置。

## 4. 制作期与运行期隐私

- 制作期使用主人提供的豆花照片和视频。
- App 只打包去背景、去声音、重新裁切编码的派生透明片段，不打包原始媒体。
- 运行时无网络、遥测、账号、素材上传或远程配置。
- 不申请 Accessibility、输入监控、屏幕录制、摄像头或麦克风权限。

## 5. 验收标准

### 视觉

- 不看名称也能认出真实豆花，不是生成的通用金渐层。
- 毛纹、脸型、眼睛、四肢、躯干和尾巴在相邻时刻连续，不得呈现整张图替换。
- 正常播放时无曝光闪烁、黑帧、白边、品红毛边、背景残留或逐帧居中抖动。
- 一个完整循环前后主体尺度和位置不重置；接缝姿态肉眼可接受。
- 窗口缩放到 200×183 pt 时仍能识别脸、眼睛、体型和尾巴。

### 功能

- 启动不抢焦点；透明区不阻挡底层应用。
- 拖动不误触点击，释放后完整留在可见区域，视频不重头。
- 暂停、隐藏、Space 切换、显示器变化和休眠/唤醒后可恢复。
- App 包内不包含 v2/v3/v4 动画帧或原始照片视频。

### 性能

- 冷启动到可见不超过 2 秒。
- 视频持续播放目标 CPU 不超过 8%，常驻内存不超过 150 MB。
- App 安装体积不超过 10 MB，主视频资产不超过 5 MB。

## 6. 0.6 统一 3D 豆花目标

- 运行时优先加载唯一的 `douhua_rigged.usdz`，真实视频变为模型缺失时的安全回退层。
- 模型网格、PBR 材质和身份只有一份；任何动作都不允许替换整只猫。
- 猫科语义骨骼覆盖躯干、颈头、双耳、五段尾和四肢；不符合骨骼合同的模型不启用。
- SceneKit 以四元数和程序化时间曲线生成四拍慢步、呼吸、观察、香箱、睡眠、摸头和尾巴反应。
- 目标追踪、耳朵定向、情绪尾巴和抬爪作为可叠加动作通道，不中断基础姿态。
- 网格生成、重拓扑、蒙皮、命名和验收按 `Docs/Douhua3DProductionSpec.md` 执行。

## 7. 后续扩展门槛

- 行走：只有正式 3D 模型通过骨骼、蒙皮和脚底防滑验收后才恢复巡逻。
- 起卧/睡眠/翻肚：只有在同一视角、尺度和光线下能够连接当前镜头时才接入。
- 不得为了增加动作数量而重新引入离散生成图切换。
- 发布前补全双显示器、Stage Manager、全屏 Space、2 小时 soak、完整 Xcode XCTest/UI Test 与 Instruments Energy/Leaks。

## 8. 像素交互原型（DouhuaPixelDemo 0.11）

该原型是用于先行验证动作语义和互动节奏的独立 App，不替代写实视频主程序的长期 3D 目标。

- 运行视觉使用基于真实豆花素材生成并统一尺度的高细节像素动作，不打包原始照片或视频。
- 最终闲置首帧是身份母版；任何跑、跳、伏地和翻滚姿态不得通过缩放整只猫产生动作。
- 新增连续体力：短跑显著消耗，走路轻微消耗，静止和伏卧恢复。
- 体力不足时，短跑先减速并等待主植足相位，再播放完整伏地序列；禁止从腾空或收腹帧直接切换。
- 伏卧使用约 6.4 秒的慢呼吸、慢眨眼、耳朵和尾尖微动循环，保持身体与地面登记不变。
- 伏卧稳定阶段点击豆花，播放一次基于真实视频的侧翻露腹与抬爪回应，结束后返回同一伏卧姿态。
- 恢复后反向播放同一关节序列起身，随后回到安静观察；起止帧须在头脸、胸腔、髋部和像素尺度上连续。
- 菜单“跳到当前窗口”选择前台应用的正常可见窗口，读取并持续跟随真实窗口编号与几何边界；不读取窗口内容、不申请录屏或辅助功能权限。
- 跳上窗口使用现有八帧跳跃关节序列和连续抛物线位移；到达后播放“落地缓冲→屈后腿→坐稳”，脚底基线与窗口顶边严格绑定。
- 窗口驻留只允许慢呼吸、慢眨眼、耳朵和尾尖微动，窗口被拖动时只更新外部面板坐标，不对猫身体叠加摇摆或追赶动画。
- 驻留稳定阶段点击豆花，播放“低头观察→肩胛前移→前爪下探轻拍→原路收回”；支撑前爪和两条后腿始终完整。
- 目标窗口关闭或最小化时，豆花先反向播放落座序列自然起身，再跳回当前屏幕地面；用户也可通过菜单主动返回。
- 地面慢走、短跑和窗口顶边行走以“已实际移动距离 / 步幅”计算步态相位；浮窗外部位置变化不得推进四肢帧。
- 地面慢走速度 16 pt/s，步幅 28 pt；短跑速度 42 pt/s，步幅 40 pt；窗口慢走 12 pt/s，窗口短跑 32 pt/s。
- 从移动转入待机、落座或伏卧时，必须先到达支撑脚着地的植足相位；边界转向后不得原地空踩。
- 自动行为的静止间隔为 12–22 秒；地面慢走每次 4–7 秒，短跑每次约 0.85–1.2 秒，不允许连续高频触发。
- 豆花可从地面低频选择可见窗口，在窗口顶边安静驻留、慢走或短跑，也可在起身后沿连续抛物线跳到另一个可见窗口。
