# 豆花 v0.9 跑累休息互动

## 真实素材观察

- 伏卧时胸口贴低，前爪紧密收拢，头仍保持圆而宽，肩背形成柔和拱线。
- 安静时主要是很慢的胸腹呼吸、慢眨眼、轻微耳动和贴地尾尖移动，不会频繁换姿势。
- 被逗时会从伏卧向一侧翻滚，露出腹部，四肢自然弯曲，前爪会朝目标伸出或抱住目标。

## 动作组

1. `tired-down`：站立植足 → 低头放松 → 前肢屈曲 → 胸口落地 → 髋部坐低 → 尾巴贴地 → 香箱伏卧。
2. `rest-loop`：稳定香箱；只有慢呼吸、慢眨眼、耳朵和尾尖微动，完整循环约 6.4 秒。
3. `rest-reaction`：休息时点击；伏卧偏向一侧 → 侧翻露腹 → 四爪弯曲/前爪抬起回应 → 翻回伏卧。

## 触发逻辑

- 体力初值 `1.0`；短跑明显消耗体力，走路轻微消耗，安静与伏卧逐步恢复。
- 短跑中体力低于阈值后，不在腾空帧切换；先减速并等待植足相位，再进入 `tired-down`。
- 休息持续约 9–13 秒；进入和退出各使用完整的伏地动作，退出时反向播放以自然站起。
- 休息中点击触发一次 `rest-reaction`，结束后继续伏卧休息，不弹出对话动作。
- 菜单与 `--action=rest` 提供可重复验收入口。

## 身份与尺度硬约束

最终运行时 `douhua_pixel_v9_idle_00.png` 是唯一身份母版。所有动作保留相同头宽、脸颊、耳距、眼位、胸腔体积、髋部体积、爪子大小、毛色花纹和像素密度。动作只改变关节、脊柱与重心；不得缩放整只猫。
