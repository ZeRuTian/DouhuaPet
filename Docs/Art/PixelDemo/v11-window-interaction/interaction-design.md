# 豆花 v0.10 窗口互动设计

## 目标

豆花与真实 macOS 窗口边界互动，而不是在透明面板里假装碰到道具。用户选择“跳到当前窗口”后，豆花沿平滑抛物线跳到最前方可用窗口的标题栏顶边，落座并随窗口移动；点击驻留中的豆花时，它低头、前倾并用前爪拍一下窗口边缘；目标窗口关闭、最小化或离开屏幕时，豆花自然起身并跳回地面。

## 物理与连续性

- 地面/窗口顶边是稳定脚底锚点，驻留时禁止整只猫上下或左右漂移。
- 跳跃位移由连续三次缓入缓出和抛物线控制，动画帧只负责关节形态。
- 落座片段从四脚着地开始，按后腿屈曲、骨盆下沉、前爪收拢的次序进入坐姿；反向播放就是起身。
- 驻留只保留慢呼吸、慢眨眼、单耳轻转、尾尖轻摆，不进行整身缩放或摇晃。
- 拍边缘从稳定坐姿出发：视线先落到窗口边缘，肩胛前移，一只前爪下探，短暂停顿，再原路收回。另一只前爪和两条后腿始终可读。
- 三组片段的首尾姿态严格衔接：`jump 末帧 -> window-settle 首帧 -> window-perch 首帧 -> window-tap 首/末帧`。

## 窗口规则

- 优先前台应用的正常层级可见窗口，否则选择 z-order 最靠前的合格窗口。
- 排除豆花自身、桌面、Dock、菜单和小于 260×160 的浮动面板。
- 使用 CoreGraphics 窗口编号持续刷新位置，不读取窗口内容。
- 豆花落点保持在窗口左右各 18 pt 的安全区内，并优先靠近当前位置，避免无意义横跨屏幕。
- 窗口拖动或缩放时，豆花位置直接绑定边界；身体不叠加追赶弹簧，避免视觉抖动。
