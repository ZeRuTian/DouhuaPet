# v0.10 真机窗口几何验收

测试日期：2026-08-05

使用 `Tests/WindowInteractionHarness.swift` 创建 `800×532 pt` 的真实 AppKit 窗口，启动已安装的 `DouhuaPixelDemo.app --action=window`，待豆花落座后移动目标窗口，再从 CoreGraphics 读取两者边界。

| 采样 | 测试窗口 Quartz 原点 | 豆花面板 Quartz 原点 | 窗口顶边与面板顶边差 |
| --- | --- | --- | --- |
| 移动前 | `(300, 248)` | `(910, 244)` | `-4 px` |
| 移动后 | `(420, 208)` | `(1030, 204)` | `-4 px` |

结果：测试窗口位移为 `(+120, -40)`，豆花面板位移同为 `(+120, -40)`，没有滞后、超调或累积漂移。固定 `-4 px` 来自 `120 px` 资源脚底基线 `112` 在 `100×60 pt` 面板中的透明安全区，实际脚底与窗口顶边重合。

关闭测试窗口 3 秒后，豆花面板从窗口顶部 `Y=204` 返回当前屏幕地面 `Y=992`，验证了“窗口消失→反向起身→跳回地面”路径。
