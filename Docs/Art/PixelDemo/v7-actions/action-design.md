# 豆花 v0.7 动作设计

## 运动原则

- 豆花的基础气质是安静观察、慢热、偶尔突然爆发；闲置时间明显长于运动时间。
- 行走和跑步的动画相位由实际屏幕位移驱动，不使用独立的固定换帧计时器。
- 慢走完整步态的屏幕步幅目标为 22 pt；短跑完整步态的屏幕步幅目标为 34 pt。
- 慢走目标速度 18–24 pt/s；短跑目标速度 58–72 pt/s。加减速阶段步频随实际速度连续变化。
- 起跳采用预压、蹬地、腾空收腿、落地缓冲四段；窗口使用平滑抛物线位移，素材只负责身体姿态。
- 对话框互动采用发现目标、抬头注视、抬近侧前爪、轻触/保持的顺序；对话框是独立窗口，不画进精灵素材。

## 自动行为节奏

- 安静观察：5–10 秒。
- 慢走巡游：3–6 秒。
- 短跑爆发：0.9–1.6 秒，低概率出现。
- 原地跳跃：约 0.75 秒，跳高 22–28 pt，落地后停顿。
- 对话互动：由菜单或点击触发，持续约 3 秒。

## 素材分组

- `walk`: 八相四足慢走循环。
- `run`: 八相猫科短跑/小幅疾驰循环。
- `jump-dialog`: 上排四帧跳跃，下排四帧对话框互动。
