# 豆花 v0.8 统一身材比例

## 来自真实素材的结论

- 豆花是紧凑、厚实的短身体型，不是长躯干的普通橘猫，也不是头大腿细的吉祥物比例。
- 头部圆而宽，脸颊饱满，耳朵小且间距宽；头大但不能超过躯干的视觉重量。
- 胸腔和髋部都厚，肩到臀的核心躯干长度约为 `1.6–1.75 个头宽`，不能超过 `1.85` 个头宽。
- 腹线柔软但不下垂成球；胸腹深度约为 `0.75–0.85 个头高`。
- 腿短而结实，腹线到脚底的可见下肢高度约为 `0.5–0.6 个头高`；前臂不能像狗或小鹿一样细长。
- 尾巴中等长、根部较厚、末端柔和变细，不是超长鼠尾，也不是蓬松狐狸尾。

## 对 v0.7 的修正

- 慢走：核心躯干缩短约 `18%`，胸腹加深约 `8%`，可见腿长缩短约 `15%`，头部不再向前漂移。
- 短跑：保留猫科躯干伸展，但“伸展”来自脊柱屈伸，不能变成另一只身长腿长的猫；头、胸腔和臀部的体积不变。
- 跳跃/对话：站立、下蹲和抬爪都使用同一头宽和躯干体积；不因姿态改变整体缩放。
- 全部动作保持固定脚底基线、固定头部尺寸、固定胸腔与髋部体积，只允许解剖所需的透视和脊柱屈伸。

## 图像身份锁

- 灰金/浅棕的金渐层毛色，背部、头顶与尾末有冷灰棕色毛尖。
- 奶油色口鼻、下巴、胸口和腹部；黄绿/橄榄色圆眼。
- 小而圆的宽间距耳朵，轻微严肃的面部表情。
- 精致、可在 `80×60 pt` Retina 窗口中识别的像素美术；不使用橙色虎斑猫、奇幻蓬松猫或卡通小猫的比例。
