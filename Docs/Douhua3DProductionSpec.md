# 豆花 3D 骨骼桌宠制作规范

版本：1.0

日期：2026-07-13

## 1. 目标

运行时只显示一个身份稳定的豆花 3D 网格。所有行走、起卧、睡眠、转头、抬爪、摆尾、被摸和追踪光标动作由同一套骨骼与程序化时间曲线驱动，不再切换整只猫的图片或镜头。

## 2. 身份与几何来源

输入优先级：

1. 主人提供的真实豆花照片与视频，用于脸型、体型、毛色、毛纹和动作节奏验收。
2. `Docs/Art/3D/identity-anchors/` 中的统一机位 AI 身份锚点，用于给单图生成 3D 模型提供干净轮廓。
3. 原有角色参考板用于人工比对，不作为运行资产。

形体必须保留：圆宽脸、绿色大眼与深眼线、粉鼻、浅色口鼻/下巴/胸口、暖金渐层短绒毛、深色头顶和背部、紧凑偏胖躯干、短腿、粗尾与深尾尖。

## 3. 网格与材质

- 中性站立 A-pose，纯侧向时四脚均可见，可正常分离左右肢体。
- 目标 60k–120k 三角形；脸、爪、耳朵和尾尖密度高于躯干。
- 四边形重拓扑应围绕肩、髋、膝、跗、颈、嘴和尾根建立环线；生成网格不允许未修复就直接蒙皮。
- 2K PBR 贴图起步：base color、normal、roughness、ambient occlusion；金渐层毛色不得烘焙强反光。
- 桌宠默认窗口只有 240×220 pt，毛发优先用细节法线、边缘噪声和少量边缘毛片，不运行高密度物理毛发。
- 交付格式为 `douhua_rigged.usdz`；根节点必须命名为 `DouhuaRoot`。

## 4. 标准骨骼

骨骼语义与实际节点名的映射位于 `douhua-rig-v1.json`。最小合同包含：

- 核心：`pelvis → spine1 → spine2 → neck → head → jaw`。
- 耳朵：`earLeft`、`earRight`。
- 尾巴：`tail1 → tail2 → tail3 → tail4 → tail5`。
- 前肢左右：`front*Upper → front*Lower → front*Paw`。
- 后肢左右：`hind*Upper → hind*Lower → hind*Paw`。

建议额外增加肩胛、爪趾、眼球和嘴角骨。躯干、耳、脸颊和呼吸可辅以 morph targets，但不得替代主骨骼运动。

## 5. 坐标与运动合同

- Y-up，模型中性朝 +X，局部 X 轴用于肢体主屈伸。
- 四脚中性姿势共享地面，不得把脚底滑动烘焙进网格动画。
- 行走为四拍慢步，不是对角蹄跳跃；踏步顺序、肩胛滑动、骨盆轻微摆动和尾巴滞后由程序化驱动器连续计算。
- 稳定状态：`walking`、`observing`、`loafing`、`sleeping`。
- 反应通道：`pet`、`lookTarget`、`earTarget`、`tailMood`、`pawTarget`，以后交互不需要替换模型或完整动画。

## 6. App 运行时

- `Douhua3DController` 优先寻找 `douhua-rig-v1.json` 指定的 USDZ。
- 模型和必需骨骼完整时，使用 `SK3DNode + SceneKit` 透明渲染。
- 动作由 `FelineRigPoseDriver` 以单调时间曲线、四元数混合和语义骨骼驱动；姿势切换不换网格。
- USDZ 缺失、骨骼命名不合同或加载失败时，安全回退到当前真实透明视频，不显示未完成的玩具猫。

## 7. AI 生成与自动绑定路线

1. 用干净侧视身份锚点生成 3D PBR 候选网格。
2. 在六视图与真实照片下审核头、体、腿、尾、背部毛色与口鼻；不合格则重生成，不绑定。
3. 对候选网格进行对称修复、四边形重拓扑、UV 和 PBR 纹理投射。
4. 用 UniRig 生成骨骼与蒙皮；根据其官方说明，尾骨缺失等骨架错误必须在蒙皮前人工修正。
5. 按本文档重命名并导出 USDZ，运行全动作与边缘变形验收。

候选工具与官方来源：

- [Microsoft TRELLIS.2](https://github.com/microsoft/TRELLIS.2)：单图生成高分辨率带 PBR 材质 GLB，MIT 许可，本地推理需 Linux + 24GB 以上 NVIDIA GPU。
- [Tencent Hunyuan3D 2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1)：形体与 PBR 纹理分离生成，混元社区许可，完整形体+纹理官方标注约需 29GB VRAM。
- [VAST-AI-Research UniRig](https://github.com/VAST-AI-Research/UniRig)：面向人、动物和多种网格的自动骨架/蒙皮，MIT 许可，需 CUDA 生态。

## 8. 验收标准

- 不播放动作时六个标准视图都能认出豆花，不是通用英短。
- 正向运动时肩、肘、腕、髋、膝、跗、尾根和颈部无坍塌、穿插、体积跳变。
- 行走循环在 1× 与 0.25× 无踏步滑动，脚底速度与窗口位移一致。
- 观察时休息时间远长于微动，不得所有骨骼持续同频摆动。
- 摸头、目标追踪和尾巴情绪可与当前姿态叠加，不中断基础时间轴。
- 默认 240×220 pt 窗口持续渲染目标 CPU 低于 8%、RSS 低于 180 MB。
